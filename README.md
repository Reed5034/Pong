# Ping Pong

A simple two-player local ping pong game built with HTML, CSS, and JavaScript.

## How to play

- Player 1: W / S
- Player 2: ↑ / ↓
- First to 7 points wins the match

## Run it locally

From the project folder:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
